RAZE RUSSIA VK BOT — FRESH BUILD
================================

Это чистая версия под Bothost/PHP 8.2 + SQLite.
Старая база не нужна: архив содержит новую пустую data/raze.sqlite.

1. Создай новый репозиторий.
2. Загрузи bot.php.
3. Загрузи папку data и файл data/raze.sqlite.
4. Запусти bot.php как основной процесс.
5. В переменных окружения оставь:
   VK_TOKEN=токен сообщества
   VK_GROUP_ID=241953865
   OWNER_IDS=831772755
   TZ=Europe/Moscow

ВАЖНО
------
Токен в код не вписывать. Храни его только в переменных Bothost.
Права папки data должны позволять PHP создавать/изменять SQLite.
Если хочешь полностью новую БД — используй data/raze.sqlite из этого архива.
Не удаляй её во время работы.

ИСПРАВЛЕНО
----------
- /help, !help, .help, /помощь, !помощь, /команды работают через единый парсер.
- Поддерживается формат !help@club... в беседах.
- !staff / /staff / !состав — отдельная команда списка администрации.
- !admin и !gadmin сначала создают пользователя в БД, затем выдают роль 80.
- Глобальная выдача ролей теперь работает даже если chat_settings для беседы ещё нет.
- Добавлены системные команды:
  /sysrole ID priority
  /sysban ID days reason
  /sysunban ID
  /sysmute ID minutes reason
  /sysunmute ID
  /syskick ID
  /sysstaff
- Системные роли с приоритетом 100 получают супер-доступ.
- /sysban и /sysmute действуют между беседами, используя VK ID.
- /syskick пытается удалить пользователя из всех известных бесед.
- pin/unpin используют VK API.
- SQLite схема содержит system_roles/system_bans/system_mutes.

ПЕРВАЯ ПРОВЕРКА
---------------
После запуска от OWNER_IDS 831772755:
/help
/staff
/admin 123456789
/staff
/sysrole 123456789 100
/sysstaff

Команды sys доступны только OWNER_IDS или пользователям с системной ролью 100+.

ОГРАНИЧЕНИЕ
-----------
Фактический VK Long Poll и права бота в беседе нельзя проверить из этого архива.
Бот должен иметь необходимые права сообщества/беседы для removeChatUser, pin/unpin и других действий.
